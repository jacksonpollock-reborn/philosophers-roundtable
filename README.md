# Philosopher's Roundtable

A local web app where AI-simulated personas (philosophers, psychologists, economists, politicians, religious figures) debate topics in threaded, multi-round discussions.

## Overview

Pick a topic (write your own, choose an evergreen one, or fetch generated "trending" topics), select a cast of personas, and watch them respond to the topic and to each other, round by round, with responses streamed live. You can also join in as a human participant. It is a personal learning tool for exploring one question from several viewpoints.

All responses are generated by a language model role-playing each persona. They are not real quotations or positions of the people named.

## Features

- 20 seeded personas, from Socrates, Nietzsche and Kant to Freud, Marx, Confucius and Lao Tzu, plus a custom persona editor
- Multi-persona threaded discussions with configurable speaking order
- Streamed responses (Server-Sent Events) rendered as Markdown
- Topic library: 10 seeded evergreen topics and LLM-generated topic suggestions
- Pluggable LLM backend: Google Gemini (default) or a local Ollama model, switchable in the Settings page
- Dark theme by default

## How it works

```
Browser (Next.js client pages)
   │  REST + SSE
   v
Next.js API routes ──> discussion engine ──> prompt builder (identity + behavior + context)
        │                      │
        v                      v
 Prisma + SQLite          LLM provider (Gemini | Ollama)
   (dev.db)               chosen from the Settings row
```

For each round, every persona in turn order sees the full message history (including earlier replies in the same round), receives a three-layer prompt, and its answer is streamed back and saved.

## Setup

Prerequisites: Node.js 20+ and npm. For Gemini, a free API key from Google AI Studio; for Ollama, a local Ollama install with a pulled model.

```bash
npm install
cp .env.example .env
npx prisma generate
npx prisma db push      # creates ./dev.db from the schema
npx prisma db seed      # loads personas, topics and default settings
npm run dev             # http://localhost:3000
```

Then open the Settings page and enter your Gemini API key (or switch the provider to Ollama).

## Configuration

| Item | Where | Purpose |
|---|---|---|
| `DATABASE_URL` | `.env` (see `.env.example`) | Read only by the Prisma CLI via `prisma.config.ts`; use `file:./dev.db` |
| Gemini API key and model | Settings page | Stored in the local SQLite database, not in `.env` |
| Ollama base URL and model | Settings page | Defaults `http://localhost:11434` and `llama3.1` |

The app itself always opens `dev.db` in the project root (`src/lib/db.ts`), so keep `DATABASE_URL` pointed at the same file. Because your API key lives in `dev.db`, that file is gitignored; never commit it.

## Usage

```bash
npm run dev          # development server
npm run build        # production build
npm start            # serve the production build
npm run lint         # ESLint
npx prisma studio    # browse the database
npx prisma db seed   # re-seed (personas are upserted; evergreen topics are added again)
```

Typical flow: Topics, pick or generate a topic, New Discussion, choose personas, then generate rounds and optionally add your own messages.

## Status / limitations

- Single-user local app: no authentication, and the API key is stored unencrypted in the local database.
- Gemini free-tier rate limits apply; the engine pauses one second between persona calls.
- Generated topics depend on the model returning parseable JSON and can occasionally fail.
- No automated tests yet.

## Disclaimer

Personas, including those based on living public figures, are fictional simulations produced by an AI model for exploration and entertainment. They do not represent what those individuals actually said or believe, and output may be inaccurate or offensive.
